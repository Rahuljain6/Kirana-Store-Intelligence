# 🏪 Kirana Store Intelligence – End-to-End Data Analytics Project


## 📌 Project Overview

Kirana Store Intelligence is an end-to-end retail data analytics project developed to analyse the business performance of a grocery store.

The project uses SQL, Python and Power BI to extract, analyse and visualise business data, helping management make data-driven decisions.

The analysis focuses on sales performance, product profitability, inventory management, supplier performance, purchase trends and product expiry monitoring.

## 🎯 Business Problem

Retail stores generate large amounts of transactional and operational data. However, without proper analysis, it becomes difficult to identify business trends, monitor profitability and manage inventory efficiently.

This project aims to convert raw retail data into meaningful insights that can help improve business performance and operational efficiency.

## 🎯 Project Objectives

- Analyse overall sales and revenue performance.
- Identify top-performing products and categories.
- Evaluate product profitability.
- Monitor inventory and stock availability.
- Analyse supplier and purchase performance.
- Identify expired and soon-to-expire products.
- Build interactive business intelligence dashboards.

## 📂 Dataset Description

The project consists of six datasets:

| Dataset | Description |
|---|---|
| Products | Product details, categories and pricing |
| Suppliers | Supplier information and ratings |
| Sales | Sales transactions and quantities |
| Inventory | Product stock information |
| Purchases | Purchase transaction records |
| Expiry Records | Batch details and product expiry dates |
